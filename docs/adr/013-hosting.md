# ADR-013: Production hosting

- **Status:** Open. Must be decided by Phase 18 (item O1).

## Context

No deployment configuration exists yet. TRD §12 says the production host must not be chosen without the owner's decision.

## Options

- **Vercel with hosted Supabase:** the suggestion.
- **Self-hosted Node with hosted Supabase**
- **Other platforms**

## Decision

Not decided yet.

## Consequences

Until this is decided:

- No deployment configuration will be added.
- Environment variable names will still be documented in `.env.example`.
